ЖЦРПО 350541

Коршунова В.В.

Название проекта: Калькулятор жизни.

Программа по введенному количеству лет, количеству часов в день, проведенному за компьютером должна вычислить сколько человек просидел за компьютером часов, суток, каков пробег курсора в километрах, сколько раз примерно человек кликнул, сколько примерно раз человек нажал на клавиатуру (используя статистические данные из интернета).
