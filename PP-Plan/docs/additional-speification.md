# Дополнительные спецификации системы

## 1. Назначение и участники

Веб-приложение «ПП-План» предназначено для составления недельного меню на основе настроек питания пользователя. Система предоставляет просмотр недельного меню и КБЖУ, сведения о блюдах и рецептах, замену выбранного блюда, список покупок, сохранение и открытие плана. Каталог рецептов изменяет менеджер каталога.

| Участник | Функции |
|---|---|
| Пользователь | Настройка профиля и ограничений, формирование меню, просмотр и редактирование плана, получение списка покупок, сохранение и открытие плана. |
| Менеджер каталога | Изменение каталога рецептов. |

## 2. Настройки профиля

Пользователь может открыть форму настройки профиля, указать целевые показатели КБЖУ, перечень аллергенов, предпочитаемые и исключённые продукты. После ввода параметров пользователь выбирает сохранение либо отмену внесённых изменений. При сохранении данные профиля используются для последующих запросов формирования меню. При отмене изменения не применяются.

Повторная настройка профиля перед каждым запросом меню не обязательна: система получает ранее сохранённые параметры питания. Если необходимые данные профиля не заполнены, пользователь направляется к форме профиля.

## 3. Формирование недельного меню

**Входные данные:** сохранённые параметры питания пользователя, включая целевые КБЖУ, аллергены и ограничения.

**Порядок обработки:**

1. Пользователь запрашивает меню на семь дней.
2. Система получает сохранённые параметры питания и проверяет их.
3. Система запрашивает в каталоге рецепты с проверенным составом, ингредиентами и КБЖУ.
4. Из набора исключаются рецепты, содержащие запрещённые ингредиенты и аллергены.
5. Из оставшихся рецептов система подбирает блюда для семи дней.
6. Система рассчитывает КБЖУ и отклонения от целевых значений.
7. Пользователю отображаются сформированное меню и показатели КБЖУ.

**Альтернативные исходы:** если данные профиля не заполнены, пользователь переходит к их настройке; если подбор невозможен, система сообщает о конфликте ограничений. Запрещённые ингредиенты и аллергены не используются для достижения целевых значений КБЖУ.

## 4. Просмотр и редактирование меню

После формирования меню или открытия сохранённого плана пользователь может просмотреть план и КБЖУ, открыть рецепт выбранного блюда, запросить список покупок либо заменить блюдо.

### 4.1. Просмотр блюда и рецепта

При выборе отдельного блюда система показывает его КБЖУ, рецепт и список продуктов. Сведения рецепта включают название, ингредиенты, их количество, число порций и инструкцию приготовления.

### 4.2. Замена блюда

1. Пользователь выбирает блюдо, которое требуется заменить.
2. Система запрашивает в каталоге альтернативные рецепты.
3. Система проверяет альтернативы на соответствие аллергенам и ограничениям.
4. При наличии подходящих альтернатив система показывает варианты замены.
5. Пользователь выбирает заменяющее блюдо.
6. Система заменяет только выбранное блюдо, пересчитывает КБЖУ и список покупок.
7. Система показывает обновлённое меню и показатели.
8. Пользователь может сохранить изменённое меню или отменить изменения.

Если подходящих блюд нет, система сообщает о невозможности замены. Остальные блюда плана не изменяются.

### 4.3. Список покупок

По запросу пользователя система отображает список покупок, составленный по ингредиентам плана с учётом количества порций. Одноимённые ингредиенты суммируются в совместимых единицах измерения; несовместимые единицы автоматически не объединяются.

## 5. Сохранение и открытие плана

Пользователь может сохранить сформированный или изменённый план. Сохранённый план впоследствии открывается для просмотра и изменения. При отмене несохранённых изменений они не применяются. При ошибке формирования меню ранее сохранённый план остаётся неизменным.

## 6. Изменение каталога рецептов

Менеджер каталога изменяет данные рецептов. Для автоматического подбора используются рецепты с проверенными сведениями об ингредиентах, массах и КБЖУ. Рецепты с неизвестным или непроверенным составом не участвуют в автоматическом подборе.

## 7. Состояния и переходы, представленные моделью

| Состояние | Событие | Следующее состояние |
|---|---|---|
| Ожидание действий | Открыть профиль | Настройка профиля |
| Настройка профиля | Сохранить настройки | Ожидание действий |
| Ожидание действий | Запросить меню | Формирование меню |
| Формирование меню | Меню сформировано | Работа с планом |
| Формирование меню | Подбор невозможен или ошибка | Ожидание действий |
| Ожидание действий | Открыть сохранённый план | Работа с планом |
| Работа с планом | Сохранить план или завершить просмотр | Ожидание действий |

## 8. Правила обработки данных и исключительных ситуаций

| Ситуация | Результат |
|---|---|
| Не заполнены параметры питания | Пользователь переходит к настройке профиля. |
| Пользователь отменил изменения профиля | Изменения не сохраняются. |
| В рецепте обнаружен запрещённый компонент | Рецепт исключается из автоматического подбора. |
| Состав рецепта не проверен | Рецепт не используется при автоматическом подборе. |
| Меню нельзя сформировать | Отображается сообщение о конфликте ограничений. |
| Безопасная замена не найдена | Отображается сообщение о невозможности замены. |
| После замены блюда изменились показатели меню | КБЖУ и список покупок пересчитываются. |
| Пользователь отменил изменения меню | Изменения не сохраняются. |
| Произошёл сбой формирования меню | Ранее сохранённый план не изменяется. |
