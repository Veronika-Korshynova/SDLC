# Глоссарий проекта «ПП-План»

| Термин | Определение | Основание |
|---|---|---|
| Пользователь | Владелец профиля, создающий и изменяющий собственный план питания. | SRS 2.4, REQ-SEC-001 |
| Администратор каталога | Лицо, поддерживающее актуальность рецептов и ингредиентов без произвольного доступа к персональным данным. | SRS 2.4; SDD 2.1 |
| Профиль питания | Сохранённые целевые значения КБЖУ, пищевые ограничения, предпочтения и число порций. | SRS REQ-FUNC-001–003, 3.1.1 |
| КБЖУ | Калорийность (ккал), белки, жиры и углеводы (г) пищи. | SRS 1.3 |
| Суточная цель КБЖУ | Заданные пользователем целевые показатели за день; отклонения отображаются явно. | SRS REQ-FUNC-001, 006 |
| Аллерген | Компонент пищи, явно отмеченный пользователем как запрещённый. | SRS 1.3 |
| Исключаемый ингредиент | Продукт, который нельзя включать в блюда независимо от причины. | SRS 1.3 |
| Жёсткое ограничение | Запрет на аллерген или исключённый ингредиент; не снимается ради достижения КБЖУ. | SDD 1.3; SRS 2.3 |
| Пищевое предпочтение | Желаемый тип питания или предпочтительные продукты, учитываемые при подборе. | SRS 1.3, REQ-FUNC-003 |
| Мягкий критерий | Желательное совпадение с КБЖУ или предпочтением, не отменяющее жёсткий запрет. | SDD 1.3 |
| Каталог рецептов | Набор рецептов с проверенным составом, массой ингредиентов и пищевой ценностью. | SDD 1.3 |
| Рецепт | Название блюда, ингредиенты, массы, порции, инструкция и расчёт КБЖУ. | SRS 1.3, REQ-FUNC-008 |
| Ингредиент | Отдельный продукт с заданным количеством и единицей измерения в рецепте. | SRS REQ-FUNC-009; SDD 2.2.3 |
| План питания | Меню на семь последовательных дней, разбитое по приёмам пищи. | SRS 1.3, REQ-FUNC-004 |
| Приём пищи | Запланированная позиция дня, для которой выбирается блюдо. | SRS REQ-FUNC-004; SDD 2.2.3 |
| Замена блюда | Изменение одного приёма пищи с повторной проверкой ограничений и пересчётом показателей и покупок. | SRS REQ-FUNC-007 |
| Список покупок | Сводные количества одноимённых ингредиентов всех блюд недели с учётом порций. | SRS REQ-FUNC-009 |
| Совместимые единицы | Единицы количества, которые допускают корректное приведение и суммирование. | SRS REQ-FUNC-009 |
| Проверенный состав | Данные, позволяющие убедиться в отсутствии явно запрещённых компонентов; неизвестный состав не считается безопасным. | SRS REQ-FUNC-002; SDD 2.2.7 |
| Заявка на генерацию | Экземпляр процесса генерации с состояниями Draft, Validating, Generating, Ready, Failed. | SDD 2.2.11 |
| Версия плана | Маркер изменения записи для выявления конфликтующих обновлений. | SDD 2.2.12 |
| SRS | Software Requirements Specification — спецификация требований к программному обеспечению. | SDD 1.3 |
| SDD | Software Design Document — описание проектных решений программного обеспечения. | SDD 1.1 |
| UML | Unified Modeling Language — язык визуального моделирования; применяется для диаграмм поведения в данной работе. | Метод лабораторной работы |
