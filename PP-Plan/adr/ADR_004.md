# ADR-004 — Выбор Svelte для пользовательского интерфейса

**Статус:** Принято

## Контекст

Для разработки интерфейса «ПП-План» необходимо выбрать технологию создания интерактивных страниц настройки профиля, формирования меню и редактирования рациона.

## Рассмотренные варианты

- **React** — библиотека для построения компонентных интерфейсов с развитой экосистемой.
- **Angular** — комплексный фреймворк со встроенными средствами организации приложения.
- **Svelte** — компонентный фреймворк с компиляцией компонентов и лаконичным синтаксисом.

## Решение

Для разработки пользовательского интерфейса выбран **Svelte**.

## Обоснование

Svelte позволяет создавать реактивные интерфейсы с небольшим объёмом шаблонного кода. По сравнению с Angular он предполагает менее сложную организацию небольшого приложения, а по сравнению с React предоставляет более непосредственную модель реактивного состояния. Это удобно для отображения и обновления меню, параметров питания и списка покупок.

## Последствия

Интерфейс разрабатывается на Svelte с использованием TypeScript. При выборе дополнительных библиотек необходимо учитывать, что экосистема Svelte меньше экосистем React и Angular.
