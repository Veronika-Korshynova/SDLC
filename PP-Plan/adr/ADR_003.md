# ADR-003 — Выбор TypeScript для разработки веб-приложения

**Статус:** Принято

## Контекст

Для разработки веб-приложения «ПП-План» необходимо выбрать язык программирования для работы с профилями пользователей, рецептами, параметрами КБЖУ и планами питания.

## Рассмотренные варианты

- **JavaScript** — динамически типизированный язык программирования.
- **TypeScript** — расширение JavaScript со статической проверкой типов.

## Решение

Для разработки веб-приложения выбран **TypeScript**.

## Обоснование

TypeScript позволяет выявлять ошибки типов на этапе разработки, явно описывать структуры данных и упрощает сопровождение кода. Это полезно при работе с параметрами питания, рецептами и расчётными показателями.

## Последствия

Необходимо настроить компиляцию TypeScript и поддерживать определения типов в актуальном состоянии.
